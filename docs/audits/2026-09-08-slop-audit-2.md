# Codebase slop audit, second pass — 2026-09-08

This pass starts from the first audit's head (`d6d16cd`, PR #12), which already contained `origin/main` at `d7c1cf2`. The branch stacks on top of PR #12.

Six sonnet investigators covered core lib, core tests, provider libs, provider tests, MCP plus Flutter UI, and examples/docs/tooling. Six sonnet workers applied the fixes, one owner per file set. The parent did the core lib consolidation, reviewed every diff, and ran the gates.

The first pass removed unused layers and weak assertions. This pass found the slop that copy-paste between agents leaves behind: the same private helper in four to ten files, two 250-line implementations of one algorithm, coverage-ignore markers that hide nothing, and test scaffolding cloned into every package. Two of the duplicates were hiding real bugs.

## What the audit retained

- `AiMotion.emphasized` is unused inside the repo but is a published theme token. Public API is not removed by this audit. Same for `StreamPartToolResult.preliminary`, which providers do not construct yet.
- Google throws a bare `StateError` for a missing API key while every other provider lets the vendor's 401 flow through as `AiApiCallError`. This is tested behavior and may be deliberate, so it is reported, not changed.
- The three middleware files (language, embedding, image) share a shape but wrap different model interfaces with different method names. Dart has no way to unify them without more code than they contain.
- The Cohere and Ollama newline-delimited JSON loops share a prefix but diverge quickly; the bearer-header helper is already one line. Neither was worth a shared function.
- The `coverage:ignore` blocks that remain in providers and MCP guard genuinely unreachable branches (a null Dio body, a URL data-content arm after a URL pre-check, a hard-coded 30 s timeout callback) and say why.
- MCP's eighteen uncovered lines (listener reconnect and session-expiry paths) are the same eighteen lines that were uncovered at the base commit, measured in a throwaway worktree.
