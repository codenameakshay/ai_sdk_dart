# Open Intelligent UI gallery

The reference app's 45 gallery programs rendered offline with this port: the
16 Intelligent UI examples, 2 dashboards over the demo data tools, the four
prompt examples, one program per component, and four compositions. Switch
the theme from the app bar. "Online services" turns on Wikimedia photo
search, OSRM street routes and map tiles.

```
fvm flutter run
```
